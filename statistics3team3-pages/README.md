
# Inventory Usage & Incentives — GitHub Pages Ready
Static-exported Next.js app optimized for GitHub Pages at:
https://mariafrc123.github.io/statistics3team3/

## Deploy
1) Push this folder to a GitHub repo named **statistics3team3** under **mariafrc123**
2) Go to **Settings → Pages** and set **Source = GitHub Actions**
3) Push to `main` — the included workflow builds & publishes to Pages automatically
4) Visit: https://mariafrc123.github.io/statistics3team3/

## Local dev
```bash
npm install
npm run dev
```
